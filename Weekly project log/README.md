#Weekly Project Log
Anas Albahri (ama456) - ECSE 395, Fall 2026

This folder is my weekly log and accountability record for the semester project. Each time I work on the project, I add a dated entry to the current week's file describing what I did, what the team decided, and what is blocking us.

Every week gets its own file: Week1.md, Week2.md, and so on. This README serves as the table of contents, listing each week's file with a short description of what it covers.

How I keep this log
I date every line item as YYYY-MM-DD.
Team meetings get full minutes: who attended, what we decided, who owns each action item.
I separate my individual contributions from the team's work.
I commit each time I work on the project instead of batching a week into one push.
